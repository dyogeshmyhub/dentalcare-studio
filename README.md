# DentalCare Studio

A professional dental hospital appointment website made with HTML, CSS and vanilla JavaScript.

## Run
1. Open this folder in VS Code.
2. Install Live Server.
3. Right-click `index.html`.
4. Choose **Open with Live Server**.

## Main features
- Dental hospital landing page
- Dentist directory and filtering
- Dental services
- Appointment booking
- Availability and time slots
- Double-booking prevention
- Digital queue token
- Patient portal
- Doctor portal
- Admin portal
- Dental records
- Prescriptions
- Live queue
- Consultation completion
- Reports
- Dark mode
- Responsive UI
- localStorage demo persistence

This is a frontend academic/demo project. Do not use localStorage for real patient health information. A real hospital system needs a secure backend, database, authentication/authorization, encryption, audit logs, backups and appropriate privacy/compliance review.
